Guide d'utilisation
Comment ajouter et gérer vos checklists
"Parce que climatiser en silence, c'est un art."

Introduction

NoClim est un outil d'analyse de checklists de cartes NBA. Il vous permet de visualiser vos checklists, d'identifier les meilleurs spots de break et de suivre les joueurs et équipes les plus représentés.

Ce guide vous explique comment préparer et importer vos checklists dans l'application afin de commencer vos analyses.

Sommaire
  1. Préparer votre fichier checklist (format Excel)
  2. Importer une checklist dans NoClim
  3. Sélectionner et lancer une analyse
  4. Gérer vos checklists (presets, suppression)
  5. FAQ & résolution de problèmes
💡 Astuce : NoClim supporte plusieurs checklists simultanément. Vous pouvez analyser toute une saison d'un coup !

1. Préparer votre fichier checklist

NoClim accepte les fichiers Excel .xlsx. Votre fichier doit contenir un onglet nommé Teams_clean avec les colonnes suivantes.

1Colonnes requises

Colonne Statut Description Exemple
Player Requis Nom du joueur. Plusieurs joueurs séparés par / LeBron James
Team Requis Nom de l'équipe. Plusieurs équipes séparées par / Los Angeles Lakers
Card Type ou Box Type Requis Type de carte (Hobby, Retail, Base, Auto...) Hobby
Numbering Optionnel Numérotation de la carte (ex: /25, /99) /99
⚠️ Attention : Les lignes sans Player ou Team seront ignorées automatiquement lors de l'import.

2Colonnes ajoutées automatiquement

Ces colonnes sont calculées par NoClim, vous n'avez pas à les renseigner :

Colonne Statut Description
Year Auto Extrait du nom du fichier (ex: 2025-26)
Product Auto Extrait du nom du fichier (ex: Topps Chrome)
Hits Auto Initialisé à 1 par défaut

3Exemple de fichier valide

Player Team Card Type Numbering
LeBron James Los Angeles Lakers Base
Stephen Curry Golden State Warriors Hobby /99
Cooper Flagg Dallas Mavericks Hobby /25
LeBron James / Anthony Davis Los Angeles Lakers Hobby /10
💡 Nommage du fichier : Incluez l'année et le produit dans le nom du fichier pour que NoClim l'extraie automatiquement.
Exemple : 2025-26-Topps-Chrome-Basketball-Checklist.xlsx

2. Importer une checklist dans NoClim

L'import se fait directement depuis la barre latérale gauche de l'application.

1Ouvrir le panneau d'import

Dans la barre latérale, cliquez sur l'icône 📤 Upload en haut à droite. Un panneau s'ouvre en bas de la sidebar.

2Sélectionner votre fichier

Cliquez sur "Choisir un fichier .xlsx" et sélectionnez votre fichier Excel depuis votre ordinateur. Le nom du fichier sélectionné s'affiche dans le panneau.

3Option "Remplacer si existant"

Si une checklist du même nom existe déjà, cochez "Remplacer si existant" pour l'écraser. Sans cette option, l'upload sera refusé si le fichier existe déjà.

💡 Mise à jour : Utilisez l'option "Remplacer" quand vous recevez une version corrigée d'une checklist déjà importée.

4Lancer l'upload

Cliquez sur le bouton "⬆️ Uploader". Une fois terminé, vous verrez un message de confirmation :

✅ 2025-26-topps-chrome-basketball-checklist — 1 257 lignes

La checklist apparaît immédiatement dans la liste à gauche, prête à être sélectionnée.

3. Sélectionner et lancer une analyse

Une fois vos checklists importées, vous pouvez les sélectionner et lancer une analyse complète.

1Naviguer par année

Les checklists sont groupées par saison dans la barre latérale. Cliquez sur une année (ex: 2025-26) pour déplier la liste des checklists disponibles.

2Sélectionner des checklists

Cochez les checklists que vous souhaitez analyser. Vous pouvez en sélectionner plusieurs simultanément. Le compteur en haut indique le nombre de checklists sélectionnées.

💡 Tout sélectionner : Cliquez sur "Tout" pour sélectionner toutes les checklists disponibles d'un seul coup.

3Lancer l'analyse

Cliquez sur le bouton 🚀 Lancer en bas de la sidebar. L'analyse se lance et les résultats apparaissent dans la zone principale.

4Naviguer dans les vues

Une fois l'analyse lancée, plusieurs onglets sont disponibles :

🌍
Vue Globale — Résumé complet : métriques, top joueurs, top équipes
💎
Autos & Patchs — Toutes les cartes autographiées et memorabilia
🔥
Logoman — Les cartes les plus rares
🧩
Simulation de Break — Analyse des spots par équipe, joueur ou lettre
📈
Tendances — Évolution par année
⚖️
Comparateur — Comparez jusqu'à 5 joueurs

4. Gérer vos checklists avec les Presets

Les presets vous permettent de sauvegarder une sélection de checklists pour la réutiliser rapidement.

1Créer un preset

1. Sélectionnez les checklists que vous souhaitez sauvegarder
2. Cliquez sur l'onglet Presets dans la sidebar
3. Saisissez un nom (ex: "Saison 25-26 complète")
4. Cliquez sur "💾 Sauvegarder"

2Charger un preset

Dans l'onglet Presets, cliquez sur le nom d'un preset pour charger automatiquement toute la sélection correspondante. Plus besoin de recocher une à une !

💡 Partage : Utilisez le bouton 🔗 dans la sidebar pour copier un lien direct vers votre sélection actuelle. Partagez-le avec vos breakmates !

3Supprimer un preset

Cliquez sur la croix ✕ à droite du preset pour le supprimer.

5. FAQ & Résolution de problèmes

❓ Mon fichier est refusé à l'upload, que faire ?
Vérifiez que votre fichier est bien au format .xlsx (pas .csv, pas .xls ancien format). L'onglet doit s'appeler exactement Teams_clean. Les colonnes Player et Team sont obligatoires.
❓ Mon fichier s'uploade mais il y a peu de lignes, c'est normal ?
Les lignes sans valeur dans la colonne Player ou Team sont automatiquement ignorées. Vérifiez que votre onglet Teams_clean ne contient pas de lignes vides en début de fichier.
❓ L'année et le produit ne sont pas bien détectés dans l'analyse
NoClim extrait l'année et le produit depuis le nom du fichier. Nommez votre fichier avec l'année en premier : 2025-26-Topps-Prizm-Basketball.xlsx
❓ Je veux mettre à jour une checklist existante
Importez à nouveau le fichier en cochant l'option "Remplacer si existant". La checklist sera écrasée avec les nouvelles données.
❓ Les badges RC (Rookie Card) ne s'affichent pas pour certains joueurs
Le badge RC s'affiche uniquement si le joueur a une carte dans son année rookie parmi les checklists sélectionnées. Si vous n'avez pas sélectionné de checklist de son année rookie, le badge n'apparaît pas — c'est voulu !
❓ La simulation de break donne les mêmes scores partout
Si vous mélangez des boxes Hobby (avec autos garanties) et Retail (sans garantie), pensez à renseigner le nombre d'autos garanties par box dans le panneau de configuration de la simulation. Cela pondère les scores en conséquence.
❓ L'application ne répond pas / charge longtemps au premier accès
Le serveur peut mettre quelques secondes à démarrer après une période d'inactivité. Patientez 10-15 secondes et rechargez la page.
