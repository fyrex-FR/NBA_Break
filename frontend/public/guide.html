🚀 Démarrer en 4 étapes

1

Choisis ton sport

Dans la sidebar à gauche, sélectionne le sport (NBA, NFL, etc.). Chaque sport a ses propres checklists et sa propre logique d'analyse.

2

Sélectionne tes checklists

Coche les checklists que tu veux analyser. Tu peux filtrer par nom, trier par année ou nombre de lignes. Regroupe tes sélections habituelles en presets pour les recharger en un clic.

3

Lance l'analyse

Clique sur le bouton LANCER en bas de la sidebar. L'analyse croise toutes les checklists sélectionnées en temps réel.

4

Explore les résultats

Navigue entre les vues via les onglets en haut. Clique sur un joueur ou une équipe pour plonger dans le détail.

Tu peux partager ta sélection en copiant le lien depuis la sidebar — l'URL contient les checklists cochées.

📥 Importer des checklists

📄 Upload direct (Excel)

  • Clique sur l'icône upload en haut de la sidebar
  • Dépose un fichier .xlsx — format standard ou format Beckett
  • Le fichier est parsé automatiquement, sans IA
  • Active "Remplacer si existant" pour écraser une version précédente

🤖 Import Intelligent (via IA)

  • Accède à la vue 📥 Import Intelligent depuis les outils ou le lien sur l'écran d'accueil
  • Texte : colle n'importe quel contenu — tableau copié depuis un site, CSV, liste, etc.
  • Fichier : dépose un .xlsx Beckett — Gemini détecte les colonnes automatiquement
  • Ajoute des instructions optionnelles pour guider l'IA (ex : "Le sport est NFL")
  • Une prévisualisation éditable s'affiche avant confirmation — modifie ou supprime des lignes si besoin
  • Renomme la checklist, puis clique Confirmer l'import
L'IA normalise automatiquement les noms des joueurs (format "Nom, Prénom" → "Prénom Nom").

🗑️ Supprimer une checklist

  • Survole une checklist dans la sidebar — une icône corbeille apparaît
  • Un token admin est requis pour confirmer la suppression

🧩 Simulation de Break

Configurer les autos garanties

  • Pour chaque checklist sélectionnée, saisis le nombre de hits par box
  • Sans saisie, toutes les checklists ont un poids égal

Choisir la méthode de break

  • Par Équipe — chaque spot = une équipe NBA
  • Par Joueur — chaque spot = un joueur
  • Par Lettre — chaque spot = une ou plusieurs lettres de l'alphabet (les noms commençant par un chiffre vont dans le spot #)
  • Par Lettre (Assignation) — mode avancé : réassigne manuellement les joueurs entre les lettres, ou crée des spots dédiés pour les stars

Lire les résultats

  • Break Score : indicateur global de valeur du spot (plus c'est élevé, mieux c'est)
  • Hot Spots : spots avec un ratio Auto/Mem particulièrement élevé
  • Part % : part du spot dans le total des cartes
  • Clique sur un spot pour voir le détail de toutes ses cartes

Exporter

  • Excel par spot : un onglet par spot avec les joueurs agrégés
  • CSV complet : toutes les cartes de tous les spots

Presets de simulation

  • Sauvegarde ta configuration (méthode + autos garanties) sous un nom
  • Recharge-la en un clic pour la prochaine session
Le mode Assignation par Lettre est idéal pour les breaks "random" où tu veux équilibrer la valeur entre les spots tout en mettant les stars en avant.

🛠️ Outils avancés

⚖️ Comparateur Joueurs

  • Compare jusqu'à 5 joueurs côte à côte
  • 5 métriques : Total cartes, Logoman, Case Hit, Auto/Mem, Checklists
  • Barres proportionnelles — le meilleur du groupe = 100%
  • Idéal pour arbitrer entre joueurs sur le marché

🧪 Détection Auto/Mem & Case Hit

  • Liste tous les types de cartes présents dans ta sélection
  • Coche 💎 Auto/Mem ou ✨ Case Hit pour chaque type mal classé
  • Enregistre les corrections — elles s'appliquent à toutes les analyses suivantes
  • Utile quand un type de carte n'est pas reconnu automatiquement

📤 Export Personnalisé

  • Choisis les colonnes à inclure : équipe, joueur, nombre de cartes
  • Filtre par catégorie : 💎 Auto/Mem ✨ Case Hit 🔥 Logoman 📄 Base
  • Choisis le tri (par équipe ou par joueur)
  • Télécharge en Excel en un clic

🏷️ Catégories de cartes

NoClim classe automatiquement les cartes en 4 catégories :

  • 🔥 Logoman — cartes Logoman, les plus rares
  • ✨ Case Hit — inserts spéciaux (Downtown, Kaboom…)
  • 💎 Auto/Mem — autographes et memorabilia
  • 📄 Base/Autre — tout le reste
Si une carte est mal classée, utilise la vue 🧪 Détection pour corriger.
